# Local Manifold Explanations with Tangent Space Regression

This repository contains the code for the TAG-DS 2026 paper "Local Manifold Explanations with Tangent Space Regression."

The environment uses Python 3.13.2 and detailed requirements can be found in `environment.yml`. LEGO (Kohli et al., 2025) points to the specific commit used for experiments in this paper.

The synthetic Swiss roll experiments are contained in the `synthetic_data` folder. Each real dataset has its own notebook in `real_data`.
